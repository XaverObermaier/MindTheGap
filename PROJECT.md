# Mind the Gap

## Purpose
AI-powered information platform for global inequality,
humanitarian crises and development issues.

## Primary SDG
SDG 10 – Reduced Inequalities

## Secondary SDGs
SDG 1 – No Poverty
SDG 3 – Good Health and Well-being

## NGO
Oxfam

## Target audience
Young adults / students interested in global issues
but overwhelmed by fragmented information.

## Core concept
Awareness → Understanding → Action

## Technology
Frontend: HTML / CSS / JavaScript (no build step, static JSON data files)
Data: Python pipeline (pipeline/fetch_worldbank_data.py) pulling live from
  the World Bank Open Data API, merged with hand-curated, cited crisis
  figures and national statistics (see README.md "Data pipeline")
Database: none — static JSON in data/, regenerated by the pipeline
AI: not part of the current project scope
